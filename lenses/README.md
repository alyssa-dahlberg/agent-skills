# lenses

Alyssa's working review lenses for the [review-lenses](../skills/review-lenses/README.md) skill.
These are the opinions, not the engine: house rules, footguns and taste. Use them if they fit;
the neutral copy-me palette is in [skills/review-lenses/examples/](../skills/review-lenses/examples/).

To use them in every repo on a machine:

```bash
ln -s "$(pwd)/lenses" ~/.review-lenses
```

A repo's own `.review-lenses/` lens with the same `name` overrides the one here.
Format: [lens-format.md](../skills/review-lenses/reference/lens-format.md).
